      用 Python 稳定地调用模型，拿到校验过的结构化结果，算得清钱和时间。

      过关 告警分诊服务 Python、Spring AI 两版都跑通；讲得清 token、上下文、温度。

    入门进阶高级专家 会用懂机制懂设计
    01 Python 速成入门11/09–11/22 · 2 周 · 52 小时 给 Java 程序员的两周：写出带类型、能异步、有测试的 Python 小服务，后面九站都用它。 0%

    知识点 7 个

    • uv 管环境和依赖（对照 Maven）
    • 语法对照：列表、字典、推导式、切片
    • 函数是一等公民：闭包和装饰器
    • 类型标注和 Pydantic 数据模型
    • asyncio：事件循环、async/await、并发请求
    • FastAPI 写接口（对照 Spring MVC）
    • pytest 写测试

    值班助手 · 这一站

    写一个 GC 日志小工具：解析停顿、算出最长和平均；再包成 FastAPI 接口，用 asyncio 同时拉 5 台机器的日志。

    怎么算过关

    • 不查资料写出：Pydantic 模型、带超时的并发请求、FastAPI 接口和测试
    • 讲清 asyncio 和 Java 线程池、虚拟线程各适合什么

    Java 老朋友

    uv ≈ Maven 加 JDK 版本管理；Pydantic ≈ DTO 加 @Valid；asyncio 像 Redis 和 Netty 的单线程事件循环，和线程池是两回事。已经熟悉 Python 的话，这站压成一周复习。

    补给站

    网络 IO 模型 Redis 线程模型与 IO 多路复用 ThreadPoolExecutor.execute 源码 Spring MVC 请求处理流程 JDK 8、17、21、25（虚拟线程） G1 和 ZGC 怎么回收（练习素材）

    02 大模型怎么工作入门11/23–12/06 · 2 周 · 52 小时 站在用它的人这边看懂模型：它一次写一个 token，为什么会编，为什么上下文越长越贵。 0%

    知识点 9 个

    • 一次只写一个 token：下一个词预测
    • token、分词和计费
    • 上下文窗口：输入输出共用，越长越慢越贵
    • 采样：temperature 和 top_p 改的是什么
    • 为什么会一本正经地编（幻觉）
    • 推理模型和“思考”：用 token 换质量
    • 注意力和 KV 缓存（只讲到够用）
    • Embedding：文本变向量，意思近的靠得近
    • 怎么选模型：能力、价格、速度、开源闭源、国内外

    值班助手 · 这一站

    三个小实验写成报告：同一段日志的 token 数和成本；温度 0 和 1 各跑 10 次看差别；把一条关键报错埋进长日志，看模型找不找得到。

    怎么算过关

    • 答得出：温度设成 0，为什么也不保证每次一样
    • 给一个调用场景，估得出大概花多少钱、多慢
    • 讲清幻觉从哪来，为什么“先查资料再回答”能缓解

    Java 老朋友

    上下文窗口 ≈ 堆内存上限，但装太满不会报 OOM，而是悄悄抓不住重点；Embedding 和 hashCode 正相反，hashCode 要散开，Embedding 要让意思近的靠在一起。

    补给站

    够用的数学：向量、点积和概率

    03 调用模型：API、提示词、结构化输出入门12/07–12/20 · 2 周 · 52 小时 把模型当一个会出错的远程服务来用：拿到校验过的结果，扛得住限流和超时，算得清成本。 0%

    知识点 8 个

    • Messages API：角色、system、多轮其实是无状态的
    • 流式输出：SSE 一边生成一边推
    • 提示词基本功：说清楚、给例子、用标签分隔
    • 结构化输出：JSON Schema、Pydantic 校验、失败重试
    • 出错怎么办：429 限流、过载、超时，退避加抖动
    • 省钱：提示词缓存和批处理
    • 换模型只改一层：模型抽象层
    • Java 版：用 Spring AI ChatClient 写同一个服务

    值班助手 · 这一站

    告警分诊服务：输入一段告警和日志，输出“类型、级别、可能原因、先查什么”。带校验、重试和限流处理。Python 一版，Spring AI 一版。

    怎么算过关

    • 连续调用 100 次，结构化结果全部通过校验（靠校验加重试兜底）
    • 实测提示词缓存命中前后的成本和延迟
    • 讲清重试为什么要退避加抖动，不加会怎样

    Java 老朋友

    多轮对话 ≈ 无状态 HTTP，每次都把整段历史带上；提示词缓存 ≈ PreparedStatement 复用，但前缀必须一字不差；结构化输出 ≈ DTO 加 @Valid，只是生成方会出错，要能重试。

    补给站

    响应时间为什么越压越长（重试反馈环） 三高知识地图（超时和重试） 从输入 URL 到页面展示 Spring Boot 自动配置（Spring AI starter） HTTP 流式与 SSE

    04 工具调用与 Agent 循环（手写）进阶12/21–01/10 · 3 周 · 78 小时 不用任何框架，亲手写出 agent：模型提议调用工具，你的代码执行，结果送回去，循环到做完。 0%

    知识点 8 个

    • 工具调用的一来一回：模型提议，你的代码执行
    • Agent 循环：调到不再要工具或到上限为止
    • 工作流还是 Agent：五种常见模式怎么选
    • 工具怎么设计：名字、描述、参数、精简的返回
    • 停止条件：步数、预算、超时
    • 沙箱：只读优先、命令白名单、隔离执行
    • 危险操作先问人
    • 并行工具调用

    值班助手 · 这一站

    v1：约 200 行手写 agent。工具有查日志、解析 GC 日志、看线程 dump、搜学习笔记；全部只读，最多 15 步。

    怎么算过关

    • 画得出一次三轮工具调用的完整消息往返
    • 拿 10 个真实排障问题测它，记下答对几个、错在哪一步
    • 说得出这个场景为什么用 agent 而不用固定流程，或者反过来

    Java 老朋友

    工具定义 ≈ RPC 接口，但模型只是“提议”调用，参数可能传错；Agent 循环 ≈ while 加状态机，但下一步由模型决定，所以一定要有上限。

    补给站

    三高知识地图（超时、幂等） JVM 内存结构（排障知识） G1 和 ZGC 怎么回收（排障知识） Linux 进程、权限与容器隔离

    05 上下文工程、记忆与 RAG进阶01/11–01/31 · 3 周 · 78 小时 管好模型眼前那张桌子：放什么、放多少，查不到的去知识库里检索。 0%

    知识点 8 个

    • 上下文工程：放什么、放哪、放多少
    • 上下文快满了：压缩、摘要、子任务隔离
    • 记忆：会话内和跨会话
    • RAG 流水线：切块、向量化、检索、重排、生成
    • 向量检索和 HNSW 索引
    • 混合检索：关键词 BM25 加向量，再重排
    • 检索好不好：命中率评测
    • 让 agent 自己决定查什么（Agentic RAG）

    值班助手 · 这一站

    接上知识库：把这个仓库的全部学习页做成 RAG（切块、向量、混合检索、重排），再加跨会话记忆。你学过的东西变成它的知识。

    怎么算过关

    • 准备 30 个问题，前 5 条结果的命中率有数字
    • 说得清切块大小怎么取舍
    • 长对话不超上下文，关键信息不丢

    Java 老朋友

    RAG ≈ 先查缓存再回源，但查到的是“相似”而不是“命中”，可能拿错；向量索引 ≈ 数据库索引，但它是近似查找，用一点精度换速度。

    补给站

    缓存穿透、击穿与雪崩 连接池与事务性能（PostgreSQL） 倒排索引与 BM25 向量索引 HNSW PostgreSQL 与 pgvector

    06 MCP 与 Skills进阶02/01–02/21 · 2 周 + 春节 1 周 · 52 小时 把工具做成标准接口，谁的 agent 都能接；把做事的步骤写成按需加载的说明书。 0%

    知识点 7 个

    • MCP 的三方：主机、客户端、服务端
    • 三种能力：工具、资源、提示词模板
    • 两种传输：stdio 和 Streamable HTTP
    • 写 MCP 服务端：Python 和 Java 各一个
    • 远程 MCP 的鉴权（OAuth）
    • MCP 的安全：不可信服务端、工具描述投毒、最小权限
    • Agent Skills：按需加载的说明书

    值班助手 · 这一站

    把工具拆成 MCP 服务端（Python 一个、Spring AI 一个），接进 Claude Code 直接用；把排障步骤写成一个 Skill，就像你现在用的 learn。

    怎么算过关

    • 你的 MCP 服务端被两个不同的客户端调通
    • 讲清 stdio 和 HTTP 传输各适合什么，远程服务端为什么要 OAuth

    Java 老朋友

    MCP ≈ JDBC 驱动或 SPI：一套接口，各家实现，客户端不用改；不同的是驱动是你挑的可信代码，MCP 服务端可能不可信。Skill ≈ 按需加载的 starter 加一份说明书。

    补给站

    Spring Boot 自动配置 Spring Security 认证与授权 网络 IO 模型 OAuth 2 授权流程

    07 框架与多 Agent高级02/22–03/14 · 3 周 · 78 小时 知道框架替你做了什么、藏了什么；会拆多 agent，也知道什么时候不该拆。 0%

    知识点 7 个

    • Python 框架主修一个：LangGraph、Claude Agent SDK、OpenAI Agents SDK 里选

    Java 老朋友

    多 agent ≈ 微服务拆分：拆了能并行，也要付协调成本，而且每个子 agent 都要重读一遍上下文。Spring AI 的 Advisors ≈ AOP 拦截器链。注意 Spring AI 2.x 建在 Spring Boot 4 上，还在 Boot 3 的项目用 1.1.x。

    Spring IoC 与依赖注入 Spring AOP 代理原理（Advisors） Spring Boot 自动配置 ThreadPoolExecutor.execute 源码 Kafka 消息可靠性与消费组 Redis Stream 与消息队列 状态机与工作流引擎 Saga 与长事务

    08 评测与可观测高级03/15–03/28 · 2 周 · 52 小时 改任何东西都用数字说话：有评测集兜住回归，有 trace 看清每一步。 0%

    知识点 7 个

    • 为什么必须评测：输出不确定，改一处坏一片
    • 评测集：从真实问题里收，50 条起步
    • 怎么打分：规则断言、参考答案、LLM 当评委
    • 不只看结果，也看过程（轨迹评测）
    • Tracing：每次模型和工具调用的耗时、token
    • 线上指标：成功率、成本、P95 延迟、转人工率

    • 改一次提示词，能用数字说出变好还是变坏，以及差别是不是噪声
    • 随便挑一次请求，看得到每一步花了多少时间和 token

    Java 老朋友

    评测集 ≈ 单元测试加压测，但结果是通过率，不是全过或全挂；Tracing ≈ SkyWalking、Zipkin 那套链路追踪，只是每一段多了 token 和成本。

    系统压测 响应时间为什么越压越长 OpenTelemetry 链路追踪 够用的统计：样本量和置信区间

    讲法：AI 部分一律从零讲

    读者是有经验的 Java 后端。经验决定讲多快、用什么打比方，不决定从哪讲起：天天调接口，也可能说不清温度设成 0 结果为什么还会变。

    AI 部分（新的）

    当零基础讲：往下讲两层，前置知识写足。每个新概念先挂到一个 Java 老朋友上，再指出哪里不像。

    例：讲 Embedding，先讲向量和距离，再讲模型怎么把一句话变成一串数，最后说它和 hashCode 哪里相反。

    Java 部分（老本行）

    从这一站要解决的问题讲起，往下讲一层；仓库里已经有的页面直接链过去，不重讲。

    例：讲限流，从“模型供应商每分钟只给 N 次”讲起，再讲令牌桶。

    下面 14 个比方是这门课的骨架：每个 AI 概念都先从你认识的东西出发。红色那行最要紧，比方失效的地方正是新东西的精华。

    调用大模型≈ 调远程 HTTP 服务03

    像有超时、有限流、要重试

    不像同样的输入，不保证同样的输出

    多轮对话≈ 无状态 HTTP + session03

    像服务端不记得你，历史每次都要发

    不像历史越长，每次越贵越慢

    上下文窗口≈ 堆内存上限02

    像装满了就会出事

    不像不报 OOM，而是悄悄抓不住重点

    提示词缓存≈ PreparedStatement 复用03

    像相同的部分不再重新算

    不像只认一字不差的前缀，改一个字就失效

    结构化输出≈ DTO + @Valid03

    像用 schema 约束格式

    不像生成方自己会出错，校验失败要重试

    Embedding≈ hashCode02

    像把内容变成定长的数

    不像意思近的要靠近，hashCode 偏要散开

    工具定义≈ RPC 接口04

    像有名字、参数、返回值

    不像模型只提议调用，执行的是你的代码；它会传错参数

    Agent 循环≈ while + 状态机04

    像每轮看结果决定下一步

    不像下一步由模型决定，必须有上限

    RAG≈ 先查缓存再回源05

    像先查外部存储，再拼出答案

    不像查到的是“相似”不是“命中”，可能拿错

    MCP≈ JDBC 驱动 / SPI06

    像一套接口，各家实现，客户端不改

    不像驱动是你挑的可信代码，MCP 服务端可能不可信

    多 agent≈ 微服务拆分07

    像拆开能并行，各管一摊

    不像每个 agent 都要重读上下文，token 成倍涨

    评测集≈ 单元测试08

    像改完跑一遍，防回归

    不像结果是通过率，要分清进步还是噪声

    护栏≈ Filter 链 / Spring Security09

    像进出都过一道检查

    不像攻击写在自然语言里，正则拦不全

    断点续跑≈ Kafka 的 offset 提交09

    像挂了从记下的位置接着跑

    不像重放一步，模型可能做出不同决定，工具要幂等
