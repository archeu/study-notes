  1. 01全景：一个 FastAPI 请求的一生站 01 的场景全景：一条 curl 进 FastAPI，经过 uv、uvicorn、路由、参数校验、端点协程、gather、事件循环、解析日志、响应模型、pytest 十站，每站挂上 Python 速成的知识点和 Java 对照；并发与串行耗时实测、order-04 超时、阻塞调用卡住事件循环，分步演示
  2. 02uv 管环境和依赖（对照 Maven）站 01 第 1 个知识点：pyproject 写意图、uv.lock 钉死整棵依赖树、.venv 按锁算出来并从全局缓存硬链接；对照 Maven 的 classpath 和最近者优先，pip 与 uv 建环境耗时实测，九个坑、团队规范、CI 与 Docker 写法，uv run 先猜再跑实验台
  3. 03全景：一句话怎么变成模型的回答站 02 的场景全景：值班助手把 order-04 的 GC 日志交给模型，经过拼请求、分词、上下文窗口、查向量表、读完输入（注意力与 KV 缓存）、算概率、采样、逐 token 循环、停下、结算核对十站，每站挂上知识点和 Java 对照；本机小模型实测分词、候选概率、温度 0 和 1、输入长度与耗时、前缀缓存、幻觉，分步演示
  4. 04语法对照：列表、字典、推导式、切片站 01 第 2 个知识点：对照 Java 讲列表和字典的内存布局、推导式和生成器、切片为什么复制而不是视图、8 个坑、推导式与生成器的速度和内存实测，切片实验台
  5. 05函数是一等公民：闭包和装饰器站 01 第 3 个知识点：函数是对象、闭包的 cell 和迟绑定、装饰器就是 f = deco(f) 且在 import 时从下往上执行、monkeypatch 改的是哪个模块的名字；对照 Java lambda 和 Spring AOP 代理，8 个坑本机复现，装饰器实验台（顺序 × wraps × 同步异步，8 种组合 FastAPI 实测）
  6. 06类型标注和 Pydantic 数据模型站 01 第 4 个知识点：类型标注是运行时不检查的元数据、Pydantic 在类定义时编译出校验器、宽松和严格模式、FastAPI 入口 422 与出口 response_model 过滤；对照 Java 编译器、Jackson 和 Bean Validation，8 个坑本机复现，校验耗时实测，Pydantic 实验台（10 种输入 × 两种模式）
  7. 07asyncio：事件循环、async/await、并发请求站 01 第 5 个知识点：协程是能在 await 处暂停的函数、事件循环用一个线程加 epoll 同时等很多 socket、gather 与 TaskGroup 出错时的区别、超时和取消是协作式的；对照 Java 线程池、Netty 和虚拟线程，阻塞与 GIL 实测，8 个坑，“一个线程的时间线”实验台
