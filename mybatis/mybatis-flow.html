MyBatis 启动时把配置和每个 Mapper XML 读一遍，一条 SQL 变成手册里的一页。运行时不再读 XML，只按编号翻页。

拼 SQL：动态标签，#{} 和 ${}

第 3 步“拼 SQL”有两件事：先按参数把动态标签算一遍，再把 #{} 换成问号。

selectByCond
<select id="selectByCond" resultType="Order">
  SELECT id, order_no, amount FROM t_order
  <where>
    <if test="status != null">
      AND status = #{status}
    </if>
    <if test="keyword != null and keyword != ''">
      AND order_no LIKE CONCAT('%', #{keyword}, '%')
    </if>
  </where>
</select>
statuskeyword拼出来的 WHERE
1nullWHERE status = ?
null"1105"WHERE order_no LIKE CONCAT('%', ?, '%')
开头的 AND 被 <where> 去掉了
1"1105"WHERE status = ? AND order_no LIKE …
nullnull没有 WHERE，整张表都查出来
<if>条件成立才留下这段
<where>有内容才加 WHERE，去掉开头的 AND / OR
<set>UPDATE 用，去掉末尾多余的逗号
<foreach>把集合展开成 IN (?, ?, ?) 或批量 VALUES
<choose>多选一，相当于 if / else if / else
<sql> + <include>抽出公共片段，比如列名清单

插件：能插在哪四个地方

    
MyBatis 只允许拦这四个对象。插件就是给它们套一层 JDK 动态代理，方法被调用时先经过你。

  

  

    
Executor
query · update · commit · rollback
例：PageHelper 分页，在这里改写 SQL、先查总数。

    
StatementHandler
prepare · parameterize · query · update
例：慢 SQL 统计、多租户自动加条件。

    
ParameterHandler
setParameters
例：入库前给手机号加密。

    
ResultSetHandler
handleResultSets
例：查出来后给身份证号打码。

  

  

    

      
一个统计慢 SQL 的插件


@Intercepts(@Signature(type = StatementHandler.class, method = "query",
        args = {Statement.class, ResultHandler.class}))
public class SlowSqlPlugin implements Interceptor {
    @Override
    public Object intercept(Invocation inv) throws Throwable {
        long start = System.currentTimeMillis();
        try {
            return inv.proceed();                // 继续往下走
        } finally {
            long cost = System.currentTimeMillis() - start;
            if (cost > 500) log.warn("慢 SQL {} ms", cost);
        }
    }
}

    

    
    
      
  • 在 Spring Boot 里声明成 @Bean 就行，自动配置会把所有 Interceptor 装进去。
    • 
      
  • 多个插件一层套一层：后登记的在最外层，最先执行。
    • 
      
  • 插件拿到的是真实对象的方法调用，改错了会影响每一条 SQL。写之前先想清楚要拦哪个方法。
    •

常踩的坑

    
先想清楚问题出在哪一步：启动时编手册、拼 SQL、查缓存，还是把行变成对象。

  

  

    
Invalid bound statement (not found)
手册里没有这一页。查 mybatis.mapper-locations 的路径；XML 放在 src/main/java 下的话，Maven 默认不打包；再核对 namespace 和 id 跟接口全名、方法名是否一致。

    
Parameter 'status' not found. Available parameters are [arg1, arg0, param1, param2]
方法有多个参数，没写 @Param，编译时又没带 -parameters，MyBatis 拿不到参数名。给每个参数加上 @Param("status")。

    
用了 ${}，被 SQL 注入
值一律用 #{}。排序列名这类只能用 ${} 的，先和白名单比对。

    
查出来 orderNo 是 null
列名 order_no 和属性名 orderNo 对不上。配 mybatis.configuration.map-underscore-to-camel-case=true，或者写 resultMap。

    
TooManyResultsException: Expected one result (or null) … but found: 2
返回单个对象的方法查出了多行。检查 WHERE 条件，或者把返回类型改成 List。

    
一级缓存：不开事务不生效，开了事务又读到旧数据
没事务时每次调用一个新 SqlSession；有事务时，同一会话里第二次查直接拿缓存，看不到别人刚改的数据。不想要它，配 local-cache-scope=statement。

    
<if test="status != null and status != ''">，status 传 0，条件没了
OGNL 把 '' 当成 0 来比，0 != '' 不成立。数字参数只判断 != null。

    
<foreach> 遇到空集合，SQL 报语法错
拼出了 IN ()。调用前先判空，空集合直接返回空结果。

    
insert 之后拿不到 id
方法返回的是影响行数。配 useGeneratedKeys="true" keyProperty="id"，id 会写回你传进去的那个对象。

    
查一个列表，日志里刷出一堆小 SQL
N+1 问题：<association> / <collection> 用了 select 嵌套查询，每一行再查一次。改成 JOIN 加 resultMap，或者打开懒加载。
